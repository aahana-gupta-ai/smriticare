# Provenance and authorship

The **Smriti concept, research framing, product direction, care workflow, and design principles** predate this public repository.

The repository itself was consolidated in **October 2026** as a public demonstration and documentation layer. Some of the later demo code, tests, synthetic examples, and documentation were created with AI-assisted development tools.

Those later additions are intended to show how the ideas can be inspected and explored; they are not presented as the original production system.

The project chronology is documented in the README and in the profile-level project timeline.
